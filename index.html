Trois types de QR

Un QR n’est pas la livraison. C’est une entrée dans le réseau : qui est relié à qui, et pour quoi. Priorité MVP : A.

Priorité MVP

A · Course

Marchand ↔ livreur. Cette livraison-ci : point de remise, commande, montant. Vie courte, pour éviter les scans morts.

Effet : lie la course et attribue le livreur. Sans compte : inscription par téléphone, puis association.

Réseau

B · Invitation livreur

Livreur → livreur. « Rejoins pour avoir des courses. » Réutilisable, plus durable.

Effet : onboard, parrain tracé. Pas besoin d’une course en cours.

Acquisition

C · Boutique / acheteur

Vers le client. Ouvre le catalogue (photo, puis audio) sans compte lourd.

Effet : commander au scan, utile si l’écriture est un frein.

Le scan lit un identifiant. Le backend route vers le bon marchand ou la bonne course — pas un numéro WhatsApp unique partagé chez Meta. Hors-ligne, le scan peut attendre en file.

Hors-ligne et synchronisation

La data coupe souvent. L’écran avance quand même. WhatsApp n’est pas le mode hors-ligne du métier.

1
Action localePhoto, scan QR, acceptation, changement d’état.
2
File sur le téléphoneRien n’est perdu. L’utilisateur voit un badge hors-ligne.
3
Retour réseauSync idempotente vers le backend : pas de doublon.
4
Ensuite seulementPush et modèles Meta (statut, boutons). Le journal WhatsApp se remplit d’un coup.

Dans le simulateur : activez « Hors ligne », avancez dans un parcours, puis revenez en ligne.

Coût WhatsApp API

Rappel court — hypothèse utilitaire, pas un devis. Groupe tarifaire Rest of Africa.

Hypothèse

50 commandes / jour / marchand × 2 messages sortants ≈ 100 messages / jour.

~6 000 FCFA

par mois et par marchand · environ 200 FCFA / jour · ~2 FCFA le message utilitaire.

À retenir

  • Entrants clients : 0.
  • Marketing : ~13 FCFA — à éviter pour un simple statut de course.
  • Depuis le 1er oct. 2026 : le « service » dans la fenêtre 24 h est au tarif utilitaire, avec 1 000 messages gratuits / numéro / mois.
  • Un numéro par marchand. Pas de numéro Meta partagé.
  • La SIM n’est pas facturée par Meta.
